## Go deeper

**If you want to understand resources, references, and bundles more deeply before moving on:**
- MITRE's "Key FHIR Resources" and "Terminology" modules, paired with the HL7 R4 spec pages for the resources you'll meet most. MITRE walks the resources clinically and at the right tempo for someone coming from a clinical background; the HL7 pages are the canonical reference every implementer keeps open while writing code. Read the MITRE pages first, then jump to the HL7 spec when you have a specific question. [mitre.github.io/fhir-for-research/modules/key-fhir-resources](https://mitre.github.io/fhir-for-research/modules/key-fhir-resources), [mitre.github.io/fhir-for-research/modules/terminology](https://mitre.github.io/fhir-for-research/modules/terminology), and [hl7.org/fhir/R4/patient.html](https://www.hl7.org/fhir/R4/patient.html) / [observation.html](https://www.hl7.org/fhir/R4/observation.html) / [bundle.html](https://www.hl7.org/fhir/R4/bundle.html).

**If you want to see this applied to real-world US clinical data:**
- The HL7 US Core Implementation Guide. US Core is the FHIR profile set most US production systems conform to. Read the "Profiles" page first; it lists every US-Core-profiled resource and what extra fields ("must-support" elements) each one adds beyond the base spec. The Patient profile alone explains why Ms. Reyes's bundle has race and ethnicity extensions and a preferred language. Track 4 of this course covers profiles and implementation guides systematically; this is the worked example that the rest of the FHIR world is built on. [hl7.org/fhir/us/core/](https://www.hl7.org/fhir/us/core/)

**If you want to go significantly further:**
- The HAPI FHIR documentation. HAPI is the open-source reference FHIR server (it powers `hapi.fhir.org`, which you'll query in Track 2). The "Getting Started" section walks resource creation, reading, search, and updates with real working examples. Even if you never run HAPI yourself, reading the docs is one of the better free introductions to what a FHIR server actually does on the inside. [hapifhir.io/hapi-fhir/docs/](https://hapifhir.io/hapi-fhir/docs/). For Python specifically, the `fhirpy` library on PyPI is a worked example of what an idiomatic FHIR client looks like on top of the same RESTful API; pair it with the GitHub repo for the source. [pypi.org/project/fhirpy/](https://pypi.org/project/fhirpy/) and [github.com/beda-software/fhir-py](https://github.com/beda-software/fhir-py).
