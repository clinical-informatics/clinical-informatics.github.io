## Go deeper

**If you want to understand profiling and validation more deeply before moving on:**
- MITRE's "Reading a FHIR IG" module walks the StructureDefinition layout (differential vs snapshot, must-support, constraints) without assuming an implementer background. Pair it with the HL7 FHIR R4 "Profiling" page, which is the canonical reference for how a StructureDefinition constrains a base resource, how slicing works, and what the spec actually says about must-support (vs the folklore around it). [mitre.github.io/fhir-for-research/modules/data-modeling-reading-igs](https://mitre.github.io/fhir-for-research/modules/data-modeling-reading-igs) and [hl7.org/fhir/R4/profiling.html](https://www.hl7.org/fhir/R4/profiling.html).

**If you want to see this applied to a real US clinical implementation:**
- The HL7 US Core Implementation Guide, with particular attention to the "Must Support" and "Quick Start" sections. US Core is the implementation guide most US production systems claim to support, and reading how it expresses things like Observation Lab, Patient race/ethnicity extensions, and the must-support list will give you the working vocabulary every US informatics conversation defaults to. Start with the Quick Start guidance, then walk one profile (US Core Patient is a useful first one). [hl7.org/fhir/us/core/](https://www.hl7.org/fhir/us/core/)

**If you want to go significantly further:**
- The HL7 official FHIR Validator (`org.hl7.fhir.validator`). Free, runs as a CLI or Java library, and is what implementers use to validate resources against profiles and implementation guides offline (rather than depending on a server's `$validate`). The README walks the common invocations: `java -jar validator_cli.jar resource.json -ig hl7.fhir.us.core` validates against US Core. The same tool also exists as a small Docker image. Builds are published from the HAPI/HL7 reference repository. [github.com/hapifhir/org.hl7.fhir.core/releases](https://github.com/hapifhir/org.hl7.fhir.core/releases) and [github.com/hapifhir/org.hl7.fhir.core](https://github.com/hapifhir/org.hl7.fhir.core). For authoring profiles (not just validating against them), the open-source toolchain is FHIR Shorthand (FSH) plus the SUSHI compiler. [build.fhir.org/ig/HL7/fhir-shorthand/](https://build.fhir.org/ig/HL7/fhir-shorthand/) and [fshschool.org](https://fshschool.org).
