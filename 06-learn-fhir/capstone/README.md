# Capstone: course 06

Author, validate, and hand off Ms. Reyes's complete FHIR record.

Eight steps (six Socratic commit-and-reveal moves plus two display panels) walk the six tracks of the course in sequence around a single real artifact: the same `fhir-bundle.json` the curriculum has used since Track 1. You decide what belongs in the bundle, propose profile stamps for every resource, triage a real cached OperationOutcome from hapi.fhir.org (22 errors and 40 warnings on the bundle as-is), prioritize fixes, set the SMART scope boundary for a downstream registry app, and place the artifact in the portability-vs-interoperability frame (with a forward look to course 07's OMOP work). The deliverable is a one-page hand-off document the learner assembles from their committed answers.

**Prerequisite:** all six tracks in course 06.

**How to start:** open `notebook.py` from the file tree on the left, then work top to bottom. Each Socratic step gates its sample answer behind a written commit from you.
