# Capstone: course 22

**Tabletop incident-response exercise. A ransomware-style intrusion detected at 03:17 affecting the EHR cluster; within 20 minutes the LIS and pharmacy systems go offline; CDS alerts stop firing; the billing system is locked. The reader works through the first 4 hours (detection, containment, communication, downtime procedures), the first 72 hours (recovery, partial restoration, patient-safety triage), and the post-incident review (lessons learned, contractual and regulatory next steps). Socratic.**

This capstone is part of the scaffold for course 22: security in clinical informatics. The notebook is a placeholder; the interactive content will be filled in as the course is built out.

**Prerequisite:** all tracks in course 22. Cross-references Course 14 (regulatory), Course 15 (executive and clinical communication during the incident), and Course 16 (operations and leadership).

**How to start (once built):** open `notebook.py` from the file tree on the left.
