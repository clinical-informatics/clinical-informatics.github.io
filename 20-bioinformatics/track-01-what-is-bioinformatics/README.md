# Track 01: What bioinformatics is and how it relates to clinical informatics

Bioinformatics is the application of computational methods to biological data. The track defines the field, names the three-segment spectrum (molecular bench bioinformatics, translational bioinformatics, clinical genomics) and where the boundary with clinical informatics sits, sketches the brief history (Human Genome Project, 1000 Genomes, ENCODE, All of Us, gnomAD), and walks Ms. Reyes's HLA-DRB1 shared-epitope test from the buccal swab her rheumatologist ordered to the line in her chart the clinician reads. The track is the orientation for the rest of the course.

**Prerequisites:** None within this course. Course 00 Track 3 (data at rest) and Course 02 Track 1 (data types) are useful anchors.

**How to start:** open `notebook.py`. Marimo loads it in app mode.

**Companion reading:** `go-deeper.md` in this folder.

**What's next:** Track 02 (genomic data structures).
