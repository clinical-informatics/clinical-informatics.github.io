# Track 05: Sharing and publication

A journal accepts the RA cohort paper on the condition that the authors complete a data availability statement and confirm the analysis follows the applicable reporting guideline. The authors now face three separate questions they had not planned for. What of the data can be shared, given that it derives from identifiable patient records? Where does the analysis code go, and in a form someone can actually run? Which reporting guideline applies to an observational cohort study, and does the manuscript contain every item it requires?

The track addresses each. **What to share and what to withhold** turns on the privacy principles from Course 03: individual-level clinical data usually cannot be posted openly, but de-identified derivatives, synthetic data, aggregate statistics, and controlled-access deposits are the graduated alternatives, and the data availability statement is where the decision is made explicit. **Code sharing** is the other half: a result is not reproducible if the data is available but the code that produced the numbers is not, and sharing code means sharing the computational environment alongside it. **Preprints** (medRxiv, bioRxiv) make a finding available immediately with a time-stamped citable record before peer review completes, and **persistent identifiers** (the DOI) keep a dataset or preprint citation resolvable after the lab server is decommissioned. The track closes on the **EQUATOR Network** and the design-specific reporting guidelines (CONSORT for trials, STROBE for observational studies, TRIPOD for prediction models, PRISMA for systematic reviews), which specify what a study of a given type must report for the work to be assessable and reproducible at all.
