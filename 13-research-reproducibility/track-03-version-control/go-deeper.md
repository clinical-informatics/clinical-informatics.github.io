## Go deeper: Version control without coding

**If you want the concept explained for a research audience:**

- [Blischak, Davenport, and Wilson, "A Quick Introduction to Version Control with Git and GitHub" (PLoS Computational Biology 2016)](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1004668) is written for scientists, not software engineers. It introduces the commit, the repository, and the GitHub pull-request workflow in the same plain-English framing this track uses, and it is open access.

**If you want to try it hands-on:**

- [Software Carpentry, "Version Control with Git"](https://swcarpentry.github.io/git-novice/) is the free, self-paced lesson the research-computing community uses to teach Git from zero. It is the natural next step once the concepts here have landed and you want to actually run a commit, and it explicitly assumes no prior experience.

**If you want to go significantly further:**

- [Chacon and Straub, "Pro Git" (2nd edition, free online)](https://git-scm.com/book/en/v2) is the complete reference. The first three chapters (Getting Started, Git Basics, Git Branching) are the ones a data-project collaborator needs; the rest is there when a question arises. Free in PDF and EPUB under a Creative Commons license.
