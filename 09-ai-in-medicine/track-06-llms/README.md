# Track 06: LLMs in clinical workflows

A large language model is a next-token predictor trained on a heterogeneous text corpus. The track defines tokenization at the intuitive level, explains hallucination as a consequence of next-token prediction rather than a fixable bug, distinguishes the tasks LLMs do well (summarization, drafting, structured extraction) from the tasks they do dangerously (diagnosis, dosing, citation generation), introduces retrieval-augmented generation as the standard mitigation pattern for enterprise clinical content, and covers the evaluation challenges that distinguish LLM evaluation from classifier evaluation (no single ground truth, no clean held-out set, prompt sensitivity).

**Prerequisites:** Tracks 01 through 05 of this course.

**How to start:** open `notebook.py`.

**Companion reading:** `go-deeper.md` in this folder.
