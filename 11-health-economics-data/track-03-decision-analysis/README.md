# Track 03: Decision analysis

A decision tree is two things at once: a picture of a clinical choice (what is being decided, what outcomes can follow, with what probability, and what value each one carries) and a math object that computes an expected value per arm. The track defines both, presents the biologic-vs-csDMARD choice for a patient like Ms. Reyes as the worked example, lets the reader move reactive probability sliders and watch the expected values move, and introduces one-way sensitivity analysis as the question of how stable the preferred strategy is under plausible variation in any single input. The Decision-tree component is inlined per the WASM rule.

**Prerequisites:** Tracks 01 and 02 of this course.

**How to start:** open `notebook.py`.

**Companion reading:** `go-deeper.md` in this folder.
