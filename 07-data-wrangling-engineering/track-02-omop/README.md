# Track 02: OMOP Common Data Model

The OMOP CDM defines a fixed schema for clinical data: six core tables that every conforming institution stores under the same names with the same columns, with each clinical fact identified by a `concept_id` drawn from a shared vocabulary. This track presents the six core tables on Ms. Reyes's record mapped to OMOP v5.4, introduces the vocabulary layer, and demonstrates the source-to-OMOP trace for one lab result.

**Prerequisites:** Track 01 of this course.

**How to start:** open `notebook.py`. Marimo loads it in app mode.

**Companion reading:** `go-deeper.md` in this folder.

**What's next:** Track 03 (SQL, the extraction layer).
