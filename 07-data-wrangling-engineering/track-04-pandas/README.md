# Track 04: pandas, the post-extraction analytic layer

pandas is the layer that follows SQL extraction. This track presents the canonical post-extraction operations (groupby and aggregate, merge with row-count checks, date conversion and time-since-event arithmetic, reactive filtering) on the same synthetic RA cohort used in Track 03. It also identifies the alternative tools (DuckDB, polars, dplyr) and the situations each is better suited to, so that pandas is positioned as the default Python choice rather than the only choice.

**Prerequisites:** Tracks 01 through 03 of this course. Course 02 Tracks 01 and 04 (data types, joins) are directly relevant background.

**How to start:** open `notebook.py`. Marimo loads it in app mode.

**Companion reading:** `go-deeper.md` in this folder.

**What's next:** Track 05 (Graph databases, conceptual).
