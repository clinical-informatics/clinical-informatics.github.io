# Track 01: Standards in the EHR

The code standards that govern clinical data in a US warehouse, the EHR location of each, and the failure modes of queries that filter on the wrong vocabulary. LOINC, SNOMED CT, ICD-10-CM, CPT, RxNorm, and NDC are presented with one canonical example each and a worked example on Ms. Reyes's record.

**Prerequisites:** None within this course.

**How to start:** open `notebook.py`. Marimo loads it in app mode.

**Companion reading:** `go-deeper.md` in this folder.

**What's next:** Track 02 (OMOP CDM).
