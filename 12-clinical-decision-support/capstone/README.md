# Capstone: Design a complete CDS intervention for a Reyes-style RA flare alert

The seven-step design brief. The reader produces a complete CDS intervention design for a Reyes-style RA flare alert across the seven dimensions every real CDS rollout has to answer: the computational decomposition of the rule (Course 01), the FHIR data the rule depends on (Course 06), the CQL logic that implements the rule (Track 02 of this course), the CDS Hook that delivers it (Track 03), the evaluation plan (Course 04), the DCA-based threshold selection (Course 11), and the equity-monitoring plan (Course 03).

Each step is a reactive form field. The Markdown summary at the end is the artifact: a CDS design brief a real implementation team could act on. The brief is exportable so the reader can carry it out of the notebook as a starting deliverable for a P&T or governance committee.

The capstone is the curriculum's grand finale. It integrates Courses 01, 03, 04, 06, 09, 10, 11, and 12 into a single end-to-end exercise.

**Prerequisites:** all five tracks in this course, plus the courses cited above.

**How to start:** open `notebook.py`. Marimo loads it in app mode.
